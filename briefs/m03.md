# M03 — Threat check

A target has a risk **score** (0–100). Rule:
- `70` or above → `"FLAG"`
- below `70` → `"CLEAR"`

## Your task
In `missions/m03_threatcheck.py`, make `classify(score)` return the right label.

## What you're learning
- **Comparisons**: `>=`, `<`, `==` produce `True`/`False`.
- **if / else** chooses what to do based on a condition.

```python
if score >= 70:
    return "FLAG"
else:
    return "CLEAR"
```
