# M03 — Weigh the cargo

A crate only comes aboard if it fits your boat's **capacity**:
- `weight <= capacity` → `"LOAD"`
- otherwise → `"LEAVE BEHIND"`

## Your task
In `missions/m03_weigh.py`, implement `decide(weight, capacity)`.

## What you're learning
- **Comparisons**: `<=`, `>`, `==` give `True`/`False`.
- **if / else** picks what to return.

```python
if weight <= capacity:
    return "LOAD"
else:
    return "LEAVE BEHIND"
```
