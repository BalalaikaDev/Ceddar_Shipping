Welcome, operator. Before the console trusts you, it needs your **callsign**.

Open `missions/m01_identify.py`. There's a function `callsign()`. Right now it
crashes on purpose (`raise NotImplementedError`). Make it **return** a string —
your handle — instead.

```python

```

## What you're learning
- A **function** is a reusable block of code. `def name():` defines one.
- `return` hands a value back to whoever called the function.
- A **string** is text in quotes: `"like this"`.
