# M01 — Sign the logbook

Welcome to the harbour, captain. Before you sail, you sign the logbook.

## Your task
Open `missions/m01_signon.py`. Make `captain()` **return** your captain name
(a lowercase, single word) instead of crashing.

```python
def captain() -> str:
    return "darius"
```

## What you're learning
- A **function** (`def name():`) is a reusable block of code.
- `return` hands a value back to whoever called it.
- A **string** is text in quotes: `"like this"`.

## Clear it
```
pytest tests/test_m01.py
```
Then `python play.py` to see your dispatch log.
