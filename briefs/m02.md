# M02 — Triangulate

Two sensors report distance readings. Command wants the **midpoint** (average).

## Your task
In `missions/m02_triangulate.py`, make `midpoint(a, b)` return the average of
`a` and `b`.

## What you're learning
- Numbers and arithmetic: `+ - * /`.
- You can `return` the result of a calculation directly: `return (a + b) / 2`.

## Clear it
```
pytest tests/test_m02.py
```
