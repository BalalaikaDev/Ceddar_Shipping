# M04 — Port scan

You get a list of port numbers. For this drill, **open ports are the even ones**.
Return just the even numbers, in the same order.

## Your task
In `missions/m04_scan.py`, implement `open_ports(ports)`.

## What you're learning
- **Lists**: ordered collections, `[22, 80, 443]`.
- **for loops**: do something for each item.
- **Modulo** `%` gives the remainder. `n % 2 == 0` means "n is even".

```python
result = []
for p in ports:
    if p % 2 == 0:
        result.append(p)
return result
```
(Later you'll learn the one-line version — a *list comprehension*.)
