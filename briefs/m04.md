# M04 — Load the hold

A line of crates waits on the dock, each a weight. Load every crate within your
`limit`, keeping dock order.

## Your task
In `missions/m04_load.py`, implement `load_hold(crates, limit)`.

## What you're learning
- **Lists**: ordered collections, `[10, 50, 30]`.
- **for loops**: do something for each crate.
- Build a new list as you go with `.append(...)`.

```python
loaded = []
for c in crates:
    if c <= limit:
        loaded.append(c)
return loaded
```
(Later you'll meet the one-line version — a *list comprehension*.)
