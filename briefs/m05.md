# M05 — Read the manifest

The **manifest** is a dictionary: crate id → value in coins. Given a crate id,
return its value — and if it's not listed, return `0` instead of crashing.

## Your task
In `missions/m05_manifest.py`, implement `value_of(manifest, crate_id)`.

## What you're learning
- **Dictionaries** map keys to values: `{"c1": 100}`.
- `manifest[key]` crashes on a missing key; `manifest.get(key, 0)` returns the
  default `0` instead. Safer.

```python
return manifest.get(crate_id, 0)
```
