# M05 — Pull a record

The case file is a **dictionary**: entity id → name. Given an id, return the
name — but if the id isn't on file, return `"UNKNOWN"` instead of crashing.

## Your task
In `missions/m05_records.py`, implement `lookup(records, entity_id)`.

## What you're learning
- **Dictionaries** map keys to values: `{"e1": "Alice"}`.
- `records[key]` crashes if the key is missing; `records.get(key, default)`
  returns `default` instead. Safer.

```python
return records.get(entity_id, "UNKNOWN")
```

This is exactly how Runi's crawlers read API responses safely — now you know why.
